# WessLess

AI-Powered Production Forecasting to Reduce Food Waste in Culinary MSMEs.

## About

WessLess adalah platform POS terintegrasi kecerdasan buatan yang bertindak sebagai **Asisten Cerdas Produksi Harian** bagi UMKM kuliner. Sistem ini membantu pelaku UMKM menentukan jumlah produksi secara lebih terukur melalui prediksi penjualan berbasis machine learning.

## Features

- **Dashboard** — Overview penjualan, waste reduction, prediksi
- **POS (Kasir)** — Pencatatan transaksi harian
- **AI Forecast** — Prediksi produksi esok hari per menu
- **Menu & Resep** — Ingredient mapping + kalkulasi HPP otomatis
- **Stok Bahan Baku** — Monitoring ketersediaan bahan
- **Smart Restock** — Rekomendasi belanja + draft WhatsApp ke supplier

## Tech Stack

- **Flutter** (Web + Android)
- **Material 3** Design System
- **fl_chart** for data visualization
- **Google Fonts** (Inter)

## Getting Started

```bash
flutter pub get
flutter run -d chrome
```
